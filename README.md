# 케어브릿지 시제품

CLover에서 재사용한 비밀번호 해시·검증 및 데이터 디렉터리 잠금 코드와 해당 내부 의존 파일을 clover-base/lib에 포함했습니다. 나머지는 케어브릿지 시제품 코드입니다. 실제 데이터·계정·환경설정·비밀키·로그 및 기존 Git 이력은 포함하지 않습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 `npm start`. 별도 패키지 설치 불필요. http://127.0.0.1:3100 접속. 원본 CLover와 다른 포트 및 저장소를 사용합니다.

바탕화면 실행·종료 아이콘과 상세 설명은 [사용안내](사용안내.html)를 참고하세요. 처음에는 관리자 계정을 직접 만든 뒤 로그인하여 작성자·돌봄 담당자·사회복지사 계정을 각각 발급합니다. 공통 시연 비밀번호는 제거됐습니다. 아이디/비밀번호 로그인, 현재 세션 로그아웃, 전체 세션 로그아웃, 비밀번호 변경을 지원합니다. 계정은 해시로 저장되고 로그인은 최대 8시간 유지됩니다. 서버 재시작 시 다시 로그인해야 합니다. 관리자 계정은 직원 관리 전용입니다.

1. 작성자로 로그인 → 영어 예시 체험 → 가상 메모 확인 → 재질문 답변 → 내용 확인 후 담당자 전달.
2. 로그아웃 → 해당 담당자 로그인 → 기록 열기 → 검토 시작.
3. 원문·번역·항목별 원문 근거 확인 → 의견 작성 → 수정 요청 또는 기록 확정.
4. 수정 요청 시 작성자 로그인 → 보완 메모 제출 → 담당자 재검토·확정.

예시 결과는 미리 작성된 고정값이며 실제 AI 성능 증거가 아닙니다. 임의 메모를 고정 예시로 처리하지 않습니다.

## 실제 AI 연결

현재 로컬 설정: Ollama의 qwen3.5:4b-q4_K_M. 입력 문맥 8192 토큰, 출력 최대 2048 토큰, 추론 모드 끔. Ollama가 실행되어 있어야 합니다. 가상 자료 검사 결과는 logs/qwen-validation.json에 저장합니다. 이 검사는 정식 번역 품질 평가를 대체하지 않습니다.


`.env.example`을 `.env`로 복사하고 설치한 다국어 Ollama 모델을 `OLLAMA_MODEL`에 지정합니다. 원본 CLover의 .env는 복사하지 않았습니다. `OLLAMA_URL` 기본값은 로컬 11434입니다. `npm start`로 재시작 후 AI 초안 생성. 연결되지 않았거나 응답 형식·원문 근거 검사가 실패하면 기록을 저장하지 않습니다. 한·영·중·베트남어 가상사례 평가는 아래 확장 평가에 기록했으며 실제 현장 품질은 검증하지 않았습니다. 외부 모델 서버를 설정하면 입력이 해당 서버로 전송됩니다.

관찰 시점/사실/발언/조치/확인 사항에 원문 발췌 근거를 요구합니다. 근거 문자열 검사는 의미의 정확성이나 환각 제거를 보증하지 않습니다. 최종 확정 전 담당자 검토가 필수입니다. 이름·주소 자동 익명화는 구현하지 않았으며 연락처·긴 숫자·이메일 탐지는 보조 검사입니다. 가상 메모만 사용하세요. 보완 메모는 재번역하지 않고 담당자에게 원문으로 표시합니다.

## 데이터와 검사

`data/accounts.json`에 계정과 비밀번호 해시를 저장하고, `data/notes.json`에 원문·초안·확정 기록·보완 및 처리 이력을 보존합니다. 저장 실패 시 메모리 변경은 적용하지 않습니다. 버전 충돌은 409로 차단하며 확정 기록은 읽기 전용입니다. 브라우저 인증은 HttpOnly SameSite 쿠키와 동일 출처 검사, 서버 역할 검사로 처리합니다. 서버 재시작 시 다시 로그인해야 합니다.

`npm test`: 상태 전이, 역할 제한, 원문 근거 검사, AI 오류, 버전 충돌, HTTP 인증·출처 제한 및 재시작 후 보존 검사. 실제 모델 품질, 실제 종사자 사용성 및 업무 절감은 별도 검증 필요.

음성 입력·기관별 계정 관리·실제 익명화·운영용 백업/삭제 정책·모바일 패키징은 이번 시제품 범위 밖입니다. 케어브릿지 후보 아이디어를 구현한 출품작이며, 공모전 참가 자격이나 기존 코드 재사용 허용을 보증하지 않습니다.


## 재질문과 담당자 전달 업데이트

새 흐름: 메모 작성 → 최대 3개 모국어 재질문 → 답변 또는 모름 → 작성자 언어 요약 확인 → 담당자에게 전달 → 검토/재배정/확정.

대상자 코드와 작성자가 선택한 업무를 담당자 표에 대조합니다. 일상 돌봄은 등록된 돌봄 담당자에게, 상담·지원 및 담당 판단 필요는 등록된 사회복지사에게 전달합니다. 관리자가 역할별 직원 계정을 1개씩 등록할 수 있으며 화면에는 등록한 이름을 표시합니다. 대상자 코드는 가상 기관의 예시 설정입니다. 이메일·문자 알림 발송은 구현하지 않았습니다. 전달은 앱 내 담당자 수신함으로 이루어집니다. 새로고침하면 최신 수신 기록을 확인할 수 있습니다. 다른 담당자는 본인에게 배정되지 않은 기록을 조회·수정할 수 없습니다. 작성자 확인 전 기록은 담당자에게 노출하지 않습니다. 담당자가 재배정하면 기존 담당자의 수신함에서 빠지며 사유가 기록됩니다.

초안·재질문·답변·이전 초안과 모름 항목을 보존합니다. 재질문은 한 차례(최대 3개) 수행하며 답변 후 남은 질문은 미해결 사항으로 담당자에게 전달합니다. 무한 반복 질문은 하지 않습니다. 예시 모드는 고정 질문만 제시하고 자유 답변을 번역하지 않으며, 그 한계를 화면에 표시합니다. 실제 AI 모드에서는 답변을 포함하여 번역·구조화 초안을 다시 생성합니다. 담당자의 별도 수정 요청에 대한 보완은 기존처럼 원문으로 표시됩니다.

로컬 qwen2.5:0.5b를 가상 영어 메모로 검사했으나, 점심을 저녁으로 바꾸고 원문에 없는 주사 관련 내용을 생성했으며 작성자용 영어 응답도 한국어로 생성했습니다. 품질 부족으로 이 모델은 기본 연결하지 않았습니다. 영어 응답에 한국어가 섞인 경우 차단 검사를 추가했으나 의미 오류 전체를 검출하는 검사는 아닙니다. 실제 사용에는 다국어 모델 선정과 별도 정답셋 평가가 필요합니다.

### 2026-10-25 Qwen 연결 점검
가상 영어·베트남어 메모 5건을 검사했습니다. 언어 지시와 예시 보강 후 약 2~4초에 응답했습니다(모델 로딩 후). 점심·저녁, 식사량, 부정 표현, 모름 및 재질문 답변 반영을 확인했습니다. 다만 담당자 보고 행동을 발언으로 분류하거나 답변된 질문을 questions에 남기는 오류가 관찰됐습니다. 항목 누락·화자 귀속도 정식 평가 전이며 담당자 확인이 필요합니다. 재질문 선택은 아직 AI 방식이고 담당자 배정은 규칙 방식입니다. 전체 질문표 기반 전환은 이번 모델 연결에 포함하지 않았습니다.

### 확장 평가 결과 (24개 시나리오, 48회 호출)

## 담당자 채팅 도구 (2026-10-28)
assistant.mjs와 /api/assistant를 추가했습니다. 조회·검토 시작·수정 요청·재배정·확정을 지원합니다. 명시적 명령은 규칙으로, 기타 표현은 로컬 모델로 분류합니다. 모델에는 요청문만 전달하며 기록 내용을 넣지 않습니다. 변경은 세션별 5분짜리 제안에 대해 실행을 명시해야 하며 사용자 권한과 기록 버전을 다시 검사합니다. 확정 내용은 사용자가 직접 작성합니다. 관리자·작성자는 접근할 수 없습니다. 사용 예시는 사용안내 7절을 참고하세요.


## 사업화 단계 개선 방향
현재 시제품은 로컬 Qwen(qwen3.5:4b-q4_K_M)을 유지합니다. 기존 가상사례 24개·48회 평가, 오류 사례와 검토 의견을 기준선으로 보존합니다. 33회 형식·근거 검사 통과와 15회 차단은 의미 정확도나 오답률이 아닙니다. 사업화 단계에서는 다른 모델을 동일 사례와 확장 정답셋으로 비교해 다국어 사실 보존, 재질문 적절성, 답변 반영, 응답시간·비용을 검증한 뒤 교체 또는 병행 도입할 계획입니다. 모델 변경만으로 정확도 향상을 보장하지 않으며 담당자의 전체 검토시간과 수정량도 함께 측정합니다.


## 외부 시연
기본 서버는 127.0.0.1에만 바인딩합니다. GitHub 업로드는 웹 서버 배포가 아닙니다. HTTPS 프록시 뒤에서 별도 시연 서버를 만들 때 createApp의 publicOrigin에 정확한 HTTPS origin을 전달하세요. 외부 모드에서는 해당 Host와 Origin만 허용하고 초기 관리자 설정 API를 차단하며 로그인 쿠키에 Secure를 적용합니다. 기존 계정·기록과 분리한 dataDir 및 새 initialAccounts를 사용하세요. 계정과 비밀번호를 저장소에 넣지 마세요. 임시 터널은 PC와 프로세스가 켜져 있을 때만 유효하며 상시 서비스가 아닙니다.

## 관리자 통합 테스트

관리자로 로그인하면 계정 관리, 모든 기록 조회, 메모 생성, 재질문 답변, 전달, 검토, 수정 요청·보완, 재배정, 확정 및 채팅 도구를 사용할 수 있습니다. 담당자 계정이 아직 없으면 새 메모를 관리자 자신에게 배정합니다. 원문 확인 및 실행 확인은 그대로 필요하며 처리 이력에 실제 관리자 이름을 남깁니다. 일반 직원의 접근 범위는 기존과 같습니다.

http://127.0.0.1:3100/ 에서 관리자 아이디와 비밀번호를 직접 입력하세요. 처음 실행이면 관리자 계정을 생성합니다. 로그인 후 영어 예시 체험 → 질문 답변 → 전달 → 검토 시작 → 수정 요청·보완 또는 기록 확정 순서로 테스트할 수 있습니다. 실제 Qwen 호출은 AI 초안 생성 버튼을 사용하세요.
